<objective>
Add `newSessionCommand` to the `AgentToolTemplate` schema so pi (and any future CLI) can declare its own session-rotation command rather than receiving a hardcoded `/new` as a literal prompt.

Purpose: This is the required schema precondition for Phase 2. Without it, a pi runner template has no place to declare its command and `resolveNewSessionCommand()` cannot read it.

Output:
- `AgentToolTemplate` and `ResolvedRunnerTemplate` gain `newSessionCommand?: string`
- `DEFAULT_AGENT_TOOL_TEMPLATES` for codex/claude set `"/new"`, gemini sets `"/clear"`
- `resolveNewSessionCommand()` reads the field instead of hardcoding the ternary
- `runnerLaunchSchema` and `runnerFamilyOverrideSchema` accept the field for config-file overrides
- Test assertions confirm field presence and runtime behavior
</objective>
